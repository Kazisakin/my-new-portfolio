# MY-NEW-PORTFOLIO

A professional developer portfolio built with React (frontend) and Node/Express (optional backend).

## Features

- **Dark Mode First** with ThemeContext
- **Glassmorphism** UI
- **Responsive** (Desktop, Tablet, Mobile)
- **Framer Motion** animations
- **Lazy Loading** of images
- **Optional Node/Express Backend** for blog data

## Installation

1. **Clone** this repository
2. Run `npm install` to install all dependencies

## Usage

- **Development**: `npm start`  
  This will run both the server (`localhost:5000`) and the client (`localhost:3000`) in parallel.
  
- **Client only**: `npm run start-client`
- **Server only**: `npm run start-server`

## Build

- `npm run build` (Builds the production-ready React app in `build/`)

## Deployment

- You can deploy the frontend separately on Vercel/Netlify
- Or deploy the entire app on a service that supports Node (Heroku, Render, etc.)
